## 📖 درباره پروژه (About)

**Tiger VPN Social Hub** یک وب‌اپلیکیشن مدرن، سبک و فوق‌العاده سریع است که تمامی لینک‌های ارتباطی، شبکه‌های اجتماعی، ربات‌های فروش و پشتیبانی تایگر وی پی ان را در یک صفحه جمع‌آوری کرده است. 

این پروژه با استفاده از جدیدترین تکنولوژی‌های وب بدون نیاز به فریم‌ورک‌های سنگین ساخته شده و به صورت **PWA (Progressive Web App)** طراحی شده است. کاربران می‌توانند این سایت را مستقیماً روی گوشی نصب کنند و حتی در حالت آفلاین نیز به لینک‌ها دسترسی داشته باشند.

---

## ✨ ویژگی‌های کلیدی (Features)

- 🎨 **طراحی مدرن Glassmorphism**: استفاده از افکت شیشه‌ای و هاله‌های نئونی.
- 📱 **قابلیت نصب (PWA)**: قابلیت نصب روی اندروید، iOS و ویندوز.
- 🌗 **تم هوشمند**: پشتیبانی از تم تاریک و روشن با تشخیص خودکار سیستم‌عامل.
- 🌍 **دو زبانه**: پشتیبانی کامل از زبان‌های فارسی (RTL) و انگلیسی (LTR).
- 📸 **ساخت QR Code**: با کلیک روی هر کارت، کد QR دریافت کنید.
- 🔍 **جستجوی زنده**: جستجوی لحظه‌ای بین تمام لینک‌ها.

---

## 🛠 تکنولوژی‌های استفاده شده

- **Frontend**: HTML5, CSS3, Vanilla JavaScript (ES6+)
- **PWA**: Web App Manifest, Service Workers
- **Tools**: QR Server API

## 🚀 راه‌اندازی و اجرای پروژه (Installation)

برای اجرای این پروژه روی سیستم خود، نیازی به نصب هیچ پکیجی (مانند Node.js یا npm) ندارید!

**۱. ریپازیتوری را کلون کنید:**

git clone https://github.com/TigerVpnGit/Bio.git

**۲. وارد پوشه پروژه شوید:**

cd Bio

**۳. فایل index.html را مستقیماً در مرورگر خود باز کنید.**

---

## 🌐 انتشار در GitHub Pages

۱. به تنظیمات ریپازیتوری خود در گیت‌هاب بروید (**Settings** > **Pages**).
۲. در بخش **Build and deployment**، شاخه **main** را انتخاب کرده و روی **Save** کلیک کنید.
۳. سایت شما در آدرس `https://tigervpngit.github.io/Bio/` در دسترس خواهد بود.

---

## ⚙️ شخصی‌سازی (Customization)

- **تغییر لینک‌ها**: به فایل `js/data.js` بروید و آرایه `LINKS_DATA` را ویرایش کنید.
- **تغییر رنگ‌ها**: به فایل `css/style.css` بروید و متغیرهای `:root` را تغییر دهید.
